# Plan Archive

## Purpose

Store archived workflow planning documents when they need to be retained beyond the active worktree control file.

## How to Enter This Section

- Use this archive for retained planning history.
- Keep the live workflow control document at the worktree root when the workflow explicitly requires `plan.md` or `todo.md`.

## What Belongs Here

- archived planning docs
- historical task breakdowns
- planning records that should remain after a workflow closes

## Naming / Maintenance Rules

- Prefer `YYYY-MM-DD_topic.md`.
- Record related intake, features, requirements, specs, decisions, and lessons.
- Record stable-doc impact before implementation.
