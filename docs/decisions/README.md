# Decisions

## Purpose

Store append-only architecture decision records for choices that shape structure, quality attributes, integration boundaries, or hard-to-reverse direction.

## How to Enter This Section

- Add a decision when alternatives were considered and the selected path should be remembered.
- Use this section for the decision and rationale, not for full feature behavior or implementation guides.
- Link superseding decisions instead of editing accepted decisions in place.

## What Belongs Here

- status, context, options considered, decision, consequences, and confidence
- supersedes / superseded-by relationships
- links to related features, requirements, specs, plans, and changes

## Naming / Maintenance Rules

- Prefer `YYYY-MM-DD_topic.md` for append-only decision records.
- Keep entries concise and factual.
- Do not hide current feature truth or technical contracts only inside decisions.
